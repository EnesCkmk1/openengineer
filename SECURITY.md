# Security

OpenEngineer executes repository code and model-selected commands. Read [docs/security.md](docs/security.md) before running it on a repository you do not trust.

Report vulnerabilities privately to the maintainers with a description, the OpenEngineer version, and the sandbox mode. Do not include live credentials or exploit payloads in a public issue.

Do not file a public issue for a missing hosted-model benchmark or for the documented limits of the process sandbox. Those are in [docs/security.md](docs/security.md) and [docs/roadmap.md](docs/roadmap.md).
